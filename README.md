# PHAGECON

Next.js App Router + TypeScript. Initial infrastructure scaffold, not the final Figma implementation.

## Local

Node.js 22 or newer. Run `npm ci`, `npm run dev`. Verify with `npm run build` and `npm run typecheck`.

## GitHub + Vercel

Intended private repository: Blendd-agencia/phagecon.
Vercel team: gads-5906s-projects (team_bZSnuiaJMPkpasBWxggnEojq).
Import the repository, select Next.js, root directory `.`, build `npm run build`. No environment variables are needed for this scaffold.
Use `main` for the main deployment and feature branches for previews. No customer domain is configured. The initial page is marked noindex; review this before final launch.
